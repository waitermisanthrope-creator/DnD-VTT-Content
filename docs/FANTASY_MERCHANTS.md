# Фэнтезийные торговцы — проект расширения рынка v1.0.0

**Статус: черновик, НЕ опубликовано в main, НЕ доступно в установленной Unity 1.00.49.**

## Содержание

- 12 разделов рынка с иерархией **раздел → торговец → список товаров**.
- 42 уже имеющихся торговца из базового Unity-рынка, плюс «Продавец экзотического оружия», «Швея / портной», «Лекарь»: всего 45.
- Предложения берутся из уже установленных проверенных `item`-пакетов каталога DnD-VTT-Content. Мод **не содержит копий предметов** и не меняет их ID, свойства, инвентарь и баланс.
- Базовый ассортимент из `unity/Assets/Vtt/Resources/CharacterSheet/market.json` сохраняется. До 32 дополнительных предложений на одного торговца выбираются по категории и ключевым словам имени. Если нужный сборник не установлен, такие предложения отсутствуют.
- Платные товары требуют известной цены из `costGp`, `price`, `baseCraftValue`, `itemTraits.trade.basePriceGp` или корректного `cost` с ПМ/ЗМ/ЭМ/СМ/ММ. Неизвестная цена не превращается автоматически в 1 зм: позиция пропускается.
- Для товара хранится `sourceItemId`: покупка использует исходное определение из установленного пакета. Товары не дублируются в JSON мода.
- Поштучные остатки рынка сохраняются в существующем состоянии рынка. Добавленные после обновления предметы получают стартовое количество 3; ранее сохранённые количества и монеты не сбрасываются.

## Пути

- Payload: `packages/dnd.market.fantasy-merchants-1.0.0.json`
- Каталог черновика: `catalog/v3/index.json`
- Схема типа: `schemas/catalog-entry-v1.schema.json`
- Unity: `DnD-VTT` → `experiment/unity-vtt`, `WorkshopStore.cs`, `CommerceRules.Market.cs`, `LegacySessionPanel.Market.cs`, `LegacySessionPanel.Commerce.cs`.
- Минимальная версия клиента в каталоге: `10050` (версия реализации ещё не выпускалась).

## Публикация и проверка

1. Выполнить `python3 tools/verify_fantasy_market.py` в репозитории Content. Для Unity выполнить существующую `WorkshopEditorValidation.Run` (проверки требуют fixtures и Unity Editor).
2. Получить **реальную** успешную Unity Android/Windows компиляцию и устройство/GUI тест с чистым и старым сохранением, с установленными сборниками оружия/брони/алхимии.
3. Проверить дерево, поиск, обмен, продажу, недостаток денег, сдачу, сохранение/повторное открытие и перестановку модов.
4. Лишь затем объединить ветку с Content `main` и открыть мастерскую в клиенте нужной версии. Живой клиент всегда читает `Content/main/catalog/v3/index.json`, не feature-ветку. **Не публиковать несовместимый тип в живом каталоге раньше клиента**.

## Ограничения

- Это списки торговых предложений, а не физические NPC/3D-модели.
- Текущая фильтрация по названиям — стартовая эвристика; предметы без цены/явного совпадения пока не предлагаются. Подбор торговца и мировая экономика дальше расширяются через Homebrew.
- Прямое добавление непроверенных скриптов и исполнительного кода модом не поддерживается.

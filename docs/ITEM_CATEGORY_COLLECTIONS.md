# Сборники модов — Unity1.00.35+

Мастерская открывается на отдельной странице «Сборники модов». Рядом находится страница «Все дополнения»; отдельные тома доступны через переключатель показа частей.

Всего 6729 существующих предметов, 103 исходных пакета. Сборники не копируют предметы и не меняют старые ID. Кнопка установки автоматически разрешает зависимости, скачивает недостающие пакеты и проверяет их SHA-256. Повторная попытка пропускает проверенные пакеты; запись сборника устанавливается последней. Для 57 пакетов хлама используются две внутренние группы по 50 и 7 зависимостей. Удаление записи сборника сохраняет тома и предметы персонажей.

Требуется новый клиент с кодом 10035 или выше. Unity1.00.34 не поддерживает автоматическую установку сборников. Ремонт и заклинание починки пока не реализованы: сломанные варианты содержат данные для будущей механики.

Генератор: `tools/build_category_collections.py`. Проверка: `python3 tools/verify_category_collections.py`; после публикации — `--public`. Публиковать сначала неизменяемые payloads, проверить `--public-payloads`, затем активировать каталог. Старые 286 записей и их payloads сохранены.

# Подводные расы для листа персонажа

Утверждено пользователем в чате 10.11.2026: куо-тоа, мерроу, тритон, сахуагин и локата; только создание листа, описания и возрастные этапы. Тексты оригинальные, народы каноничные. Для неигровых народов параметры являются явно обозначенной адаптацией, а не официальной игровой расой.

Используем существующие JSON race-пакеты Content v3: desc виден при создании, seed.raceFeatureDescriptions переносится в лист. Возраст — справочный текст, без изменения правил и автоматических штрафов. Детство, подростки, взрослые, пожилые и старые идут без перекрытий; неизвестные канону границы и пределы помечаются как авторский ориентир. Тритон: взросление около 15, жизнь до 200 лет; локата: около 10 и 80 лет. Остальным не приписываем неподтверждённую каноническую продолжительность жизни.

Подходы: выбран декларативный контент, который установленный клиент скачивает без сборки; изменение движка и 3D исключены объёмом запроса. Тритон сохраняет ID и параметры, получает новую версию/URL. Четыре новые расы устанавливаются отдельно, тематический сборник содержит пять пакетов, общий сборник рас расширяется до 47 пакетов. Старые payloads неизменны.

Публикация: рабочая ветка Content, затем проверенная доставка в Content main (так устроена мастерская experiment/unity-vtt). Main основного приложения не изменяется. Проверки: схема, SHA/размеры, IDs, зависимости и ограничения текущего WorkshopStore; по возможности запуск реальных C# обработчиков. Публичные URL проверяются после публикации. Проверка на физическом устройстве не подразумевается.

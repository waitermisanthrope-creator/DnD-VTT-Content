# Расширенные сборники — Content v4 (подготовлено, не выпущено)

Нужен новый Unity-клиент с Content v4, пределом 5000 предметов на пакет,
страницами справочника и встроенными в item-пакет materials/ingredients.
Публичный v3 и все старые JSON сохранены байт в байт. Не направлять старые
клиенты на v4. Новый APK/EXE ещё не собран и не проверен на устройствах.

Пять независимых дополнений, версия 2.0.0:

| ID | Записей |
|---|---:|
| dnd.items.weapons | 1302 |
| dnd.items.armor | 735 |
| dnd.items.materials | 621 |
| dnd.items.consumables | 232 |
| dnd.items.junk | 421 |

Всего 3311 записей. Большая часть оружия — 62 базовые записи и 1240
комбинаций материала/магического бонуса. Броня включает 540 вариантов отделки
45 основ и 150 предметов одежды. Это варианты, а не 3311 различных механик.
Вес, описание и категория есть у всех. Новые описания оригинальные;
унаследованные механические поля/ID сохранены. Бонусы атаки и формулы урона
хранятся в оружии; автоматическое подключение к полноценному боевому движку
не добавлено этим этапом. Экипировка сохраняется; тело и щит занимают по одному
слоту. Необычные свойства и косметическая отделка не выдают себя за новые эффекты.

Обычные лечебные зелья бросают 2d4+2 / 4d4+4 / 8d4+8 / 10d4+20.
Новые лечебные расходники дают явно указанное число ОЗ. Применение расходует
единицу; отсоединённый/удалённый предмет нельзя применить повторно. Еда и
прочие ручные расходники списываются кнопкой, эффект разрешает мастер.

Материалы включают 54 общих части (18 × животное/монстр/гуманоид).
Например, `harvest_monster_heart` — «Сердце монстра». Старые распознанные
видовые части показывают общее название, сохраняя legacyName/ID для миграции.
Общие части несут aliases старых craft/alchemy ID: общий дроп пригоден для
унаследованных требований. Видовые алхимические профили сохраняют отдельные
ID/химию для совместимости, хотя их названия унифицированы. Старые инвентари
не переписываются автоматически. Источники без явно распознанного вида
сохраняют прежнее название. Нужен последующий ручной аудит всей номенклатуры.
Таблицы существ/интерфейс разделки и баланс добычи в этом этапе не добавлены.

Все 120 ингредиентов и профили перенесены внутрь сборника материалов.
Три прежних дополнения ингредиентов отсутствуют только в новом каталоге;
публичные payload/v3 сохранены. Уже установленные старые ингредиенты не
дублируют записи при объединении. Сохранены самостоятельные дополнения
правил алхимии и 47 рецептов: удалять их значило бы потерять механику.
Минеральные/растительные заготовки без рецептов прямо обозначены как таковые.

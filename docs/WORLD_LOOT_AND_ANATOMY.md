Для плаценты/пуповины дополнительно указано условие соответствующей репродукции.

Названия общие: **«Селезёнка гуманоида»**, не «Селезёнка гоблина».
`harvest_humanoid_spleen` — одновременно craftMaterialId и alchemyId.
Сведения «гоблин», сборщик и время предусмотрены отдельно от имени предмета.

Для **219 общих частей** есть работающие профили: 165 новых + 54 уже
существовавших. Старые 54 образца используются по их прежнему имени/ID,
не добавлены второй раз. Всего с прежними ингредиентами доступно 339 профилей.

1. Установить нужный сборник органов и добавить образец в инвентарь.
2. Для исследования установить прежние «Алхимия 2.0 — правила и катализаторы»,
   затем нужный новый пакет «Алхимия: исследование органов …».
3. Инвентарь → «Алхимия 2.0» → поиск по «Селезёнка» → «Исследовать образец».
4. Свойство открывается в `alchemyState.discovered` этого персонажа. Исследование
   сохраняет образец; смешивание реально расходует выбранные образцы.

В описании самого органа эффектов нет; установка профилей не обучает персонажа
автоматически. UI показывает открытые свойства, а игрок может экспериментировать
с неизвестными ингредиентами по существующим правилам. Это игровое исследование,
а не защита публичных JSON от чтения вне приложения. Профили — авторские игровые
значения, не биологические/медицинские утверждения.

## Бытовые действия и данные для следующего этапа

Нож для масла весит 0.06 кг, имеет явное применение «намазывать масло и резать
мягкую пищу» и может экипироваться как импровизированное оружие 1d4 дробящего.
Это не острый мясницкий нож. Резка/работа инструментами и обстоятельства атаки
разрешаются мастером; новая кнопка автоматической разделки не добавлена.

У всех новых предметов есть вес, описание, цена и `itemTraits` по схеме
`schemas/item-traits-v1.schema.json`:

| Поле | Назначение и статус |
|---|---|
| materialTags | Материалы для будущих правил переработки |
| lootTags | Контекст находки: кухня, кузница, разделка и т. д. |
| uses | Явные ручные применения, execution=manual |
| stateDefaults | Начальные состояние/свежесть как данные; автоматических таймеров нет |
| trade | Справочная базовая цена в зм и подходящие торговцы; не автоматическая продажа |
| processing | Материалы/теги будущих рецептов, execution=planned |
| anatomy | Группа, часть, единица образца и условия наличия |
| research | Ссылка на реально поддерживаемый алхимический профиль и существующее хранилище знаний |
| provenanceFields | Поля для будущего заполнения происхождения при добыче |

Цены являются начальными ориентирами для будущей балансировки, не итоговой
автоматической экономикой.

Текущий JObject-инвентарь сохраняет эти данные и неизвестные поля через
экспорт/импорт. Происхождение может быть записано вручную. Автоматическое
заполнение при разделке, разделение стопок по происхождению/свежести, порча,
новые рецепты, торговые транзакции и таблицы добычи **ещё не реализованы**.
Текущий AddItem объединяет одинаковые предметы без учёта нового происхождения:
до доработки этой механики нельзя обещать разные источники на одной стопке.
Новые бытовые расходники реально списываются кнопкой, без фиктивного эффекта ОЗ.
Одежда экипируется, но не выдаёт неописанных бонусов защиты/навыков.

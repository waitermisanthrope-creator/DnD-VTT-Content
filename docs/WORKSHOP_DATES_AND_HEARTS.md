# Даты и рейтинг мастерской — Unity1.00.38+

`publishedAt` — первая публикация ID, `updatedAt` — последняя публикация новой версии/содержимого, UTC ISO8601, например `2026-10-23T19:06:24Z`. При новой версии сохраняйте publishedAt, изменяйте updatedAt на фактическое время публикации. Обновляйте также updatedAt зависимых сборников. Редактирование превью, описания или самого каталога не делает старый payload новым. Исторические даты восстановлены по полной git-истории, без изменения ID, версий, байтов или SHA payload. Для впервые мигрированных модов дата означает первое появление в данном публичном реестре.

Рейтинг и личное избранное хранятся в Supabase отдельно от каталогов. Сердечко = избранное; один аккаунт/ID = один голос, повторное нажатие удаляет голос. Версии одного ID сохраняют рейтинг. Нельзя указывать рейтинг или пользовательские голоса в JSON мода.

Новый ID после публикации зарегистрируйте через доверенный SQL Editor в том же проекте:

```sql
insert into app_private.workshop_mods(id) values ('your.stable.mod-id') on conflict do nothing;
```

Ключей администратора в моде или приложении быть не должно. Старая версия мода и исторические каталоги сохраняются. Пока ID не зарегистрирован, новый мод доступен для скачивания, сердечко для него недоступно.

Развёртывание функций рейтинга: [инструкция и готовая миграция в Unity-репозитории](https://github.com/waitermisanthrope-creator/DnD-VTT/blob/experiment/unity-vtt/docs/unity-account/WORKSHOP_HEARTS_1.00.38.md).
